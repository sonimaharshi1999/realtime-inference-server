  Real-Time ML Inference Server

Author: Maharshi Soni
Category: model-serving
Difficulty: advanced

----------------------------------------------------------------------
DESCRIPTION
----------------------------------------------------------------------
FastAPI + WebSocket real-time ML inference server with batched prediction, model hot-reloading, A/B testing, health monitoring, and in-memory feature cache.

----------------------------------------------------------------------
TECH STACK
----------------------------------------------------------------------
  - fastapi
  - uvicorn
  - websockets
  - scikit-learn
  - numpy
  - pydantic
  - httpx
  - pytest

----------------------------------------------------------------------
FEATURES
----------------------------------------------------------------------
  * WebSocket streaming predictions
  * REST batch inference
  * Model hot-reloading
  * A/B testing
  * Feature cache with TTL
  * Health monitoring

----------------------------------------------------------------------
SAMPLE INPUT
----------------------------------------------------------------------
  Feature vectors

  Example:
    curl -X POST /predict -d '{"features": [1.2, 3.4, 5.6]}'

----------------------------------------------------------------------
SAMPLE OUTPUT
----------------------------------------------------------------------
  Predictions with metadata

  Example:
    {"prediction": 1, "probability": 0.87, "model": "v2"}
